# Töövoofailid

Siia lisab operaator jaama salvestajaga loodud versioonitud JSON-failid, kui failikuju ning ühine MG400 lüüs on kinnitatud. [Failikuju ja näide](../docs/workflow.md#faili-kuju)

Kasuta failinime `<name>-v<version>.json`. Käivitusel peavad faili CAD-i, koordinaadiraami ja kalibratsiooni viited sobima kohaliku jaamaga. Seo kasutatud versioon tsüklikirje, seansi andmete ja katsetõendiga. Praegu ootavad jaamas õpetatud töövood kohalikku rakendust ja kontrolli.
